# <img src="logo.png" width="32"/> Kwi

Kwi is a modern and fast terminal for KDE Plasma and other desktops.

Kwi also provides modern and fast terminal components for embedding to KDE/Qt developers.

It is built on libghostty-vt and KDE Frameworks such as KPty and Kirigami.

The project includes:

* The Kwi main application.
* A public QML module API for embedding into Qt Quick/Kirigami-based apps.
* A KPart plugin for embedding into QWidget-based apps.

The Kwi application and KPart use the QML module.


## Get in touch

Join [#kwi:kde.org](https://matrix.to/#/#kwi:kde.org) on Matrix for user and developer chat.


## Dependencies:

- CMake 3.28+
- Qt 6.10+
- KDE Frameworks 6.29+
- Kirigami Addons 1.11+
- Kirigami App Components 1.1+
- libghostty-vt 1.4.0+ (either CMake or PkgConfig)
